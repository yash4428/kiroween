# Spooky macOS Overlays

Use this Power when implementing or reviewing macOS overlay windows, coordinate conversion,
Accessibility targeting, SpriteKit effects, or pass-through interaction. Prefer the current
`plugin.json` plus `skills/` metadata; this `POWER.md` remains as legacy Kiro compatibility and a
human-readable entry point.

The skill requires pure coordinate transforms, one window set per display, nonactivating panels,
body-only or object-only hit testing, Reduce Motion alternatives, finite effects, generation-safe
callbacks, and measured performance.
