# Kiro journal procedure

When explicitly requested with `#kiro-journal`, append one entry to `docs/KIRO_JOURNAL.md`:

```markdown
## YYYY-MM-DD HH:MM:SS ZONE
- Built: factual files or behavior completed.
- Kiro feature used: the actual Kiro capability and how it contributed.
- Problem or lesson: a real failure, correction, blocked permission, or concrete lesson.
```

Do not invent hook firings, MCP calls, agent runs, screenshots, measurements, commits, or external
service results. Mention the validation command and exact test count when available.
